# Support

QC Tone Architect is maintained by volunteers in their spare time.

- For reproducible bugs and focused feature requests, open a GitHub issue after
  reviewing the templates.
- For usage questions, check the compatibility, provider, and hardware-workflow
  sections in [README.md](README.md) first.
- For security-sensitive reports, follow [SECURITY.md](SECURITY.md) instead of
  opening a public issue.

Please do not include API keys, Codex credentials, device serial numbers, raw
captures, personal paths, commercial IRs, or proprietary plugin material in
public support requests.
